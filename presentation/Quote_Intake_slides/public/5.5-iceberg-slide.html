UNDER THE HOOD
One platform, zero friction
GPU server, OCR service, and Streamlit app are all dockerized and run together inside Snowpark Container Services — one ecosystem, shared secrets, and no glue code between platforms
Run once, reuse forever
Page images, OCR output, and matched field positions are all cached to Snowflake stage after the first run — reloading results is instant, no recomputation needed
Right value, not just any match
When the same value appears multiple times in a document, the system picks the occurrence whose row label best matches the field name — not just the first fuzzy hit
Corrections captured, ready for training
Every user flag is stored in Snowflake with field key, extracted value, and suggested fix — the feedback dataset is being built now, ready to drive future fine-tuning
